# Калькулятор химчистки ковров

Веб-приложение для расчёта стоимости химчистки ковров и оформления заказов с интеграцией в Битрикс24.

## 🚀 Возможности

- Расчёт стоимости химчистки ковров с учётом размеров, формы и услуг
- Поддержка нескольких ковров в одном заказе
- Выбор даты и временного слота для забора ковров
- Автоматическое создание лидов в Битрикс24
- Адаптивный дизайн для мобильных устройств

## 🛠 Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS** — стилизация
- **Битрикс24 REST API** — интеграция с CRM

## ⚙️ Настройка Битрикс24

### 1. Создание входящего вебхука

1. Откройте ваш портал Битрикс24
2. Перейдите в раздел **Приложения → Разработчикам**
3. Выберите вкладку **Готовые сценарии** → **Другое** → **Входящий вебхук**
4. Заполните параметры:
   - **Название**: Химчистка ковров
   - **Описание**: Создание лидов из калькулятора
5. В разделе **Права доступа** включите:
   - **crm** — работа с CRM (лиды, сделки)
6. Нажмите **Сохранить**
7. Скопируйте URL вебхука (вида `https://ваш-домен.bitrix24.ru/rest/1/xxxxxxxxxxxxx/`)

### 2. Настройка вебхука в коде

Откройте файл `src/bitrixApi.ts` и замените значение константы `BITRIX_WEBHOOK_URL`:

```typescript
const BITRIX_WEBHOOK_URL = 'https://ваш-домен.bitrix24.ru/rest/1/ваш-код-вебхука/';
```

### 3. Создание пользовательских полей в CRM (опционально)

Для хранения дополнительных данных создайте поля в Битрикс24:

1. Перейдите в **CRM → Настройки → Пользовательские поля**
2. Создайте поля:
   - **UF_CRM_DATE_ZABORA** (дата) — Дата забора
   - **UF_CRM_SLOT_ZABORA** (строка) — Временной слот
   - **UF_CRM_TOTAL_PRICE** (число) — Общая стоимость
   - **UF_CRM_ADDRESS** (строка) — Адрес доставки

## 🧮 Логика расчёта

### Базовые цены (за м²)

- Базовая стирка: 450 ₽/м²
- Стандартная стирка: 650 ₽/м²
- Экспресс стирка: 850 ₽/м²

### Дополнительные услуги

- Влажный ковёр: +15% к стоимости
- Удаление пластилина/слайма: 100 ₽/м²
- Удаление запаха: 100 ₽/м²
- Доставка: 1000 ₽ (фиксированная)

### Формы ковров

- **Прямоугольник**: площадь = длина × ширина
- **Овал**: площадь = π × (длина/2) × (ширина/2)
- **Круг**: площадь = π × (диаметр/2)²

## 🌐 Деплой

### Vercel (рекомендуется)

1. Загрузите проект в GitHub
2. Импортируйте репозиторий в [Vercel](https://vercel.com)
3. Vercel автоматически определит Vite и настроит сборку
4. Настройки:
   - Build Command: `npm run build`
   - Output Directory: `dist`

### Netlify

1. Загрузите проект в GitHub
2. Импортируйте репозиторий в [Netlify](https://netlify.com)
3. Настройки:
   - Build Command: `npm run build`
   - Publish Directory: `dist`

### GitHub Pages

1. Установите `gh-pages`: `npm install -D gh-pages`
2. Добавьте в `package.json`:
   ```json
   "scripts": {
     "deploy": "gh-pages -d dist"
   }
   ```
3. Выполните: `npm run deploy`

## 🔒 Безопасность

⚠️ **Важно**: URL вебхука Битрикс24 виден в клиентском коде. Для продакшена рекомендуется:

1. Создать серверный прокси (Node.js/PHP)
2. Фронтенд отправляет данные на ваш сервер
3. Сервер обращается к Битрикс24, не раскрывая вебхук

Альтернатива: использовать Cloudflare Workers или Vercel Functions как прокси.
